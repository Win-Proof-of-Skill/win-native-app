## Relationship to Liberdus

The Win Proof of Skill network is a **fork of [Liberdus](https://github.com/Liberdus/server)**, built on the Shardus distributed ledger framework. This app is a client for that network and follows the account, transaction, and messaging model it inherits from Liberdus.
